# Whisker Haven

Build a mobile app for adult cat rescue and shelter operations management.



**Authentication & Access:**

No auth required. Open directly to the main shelter dashboard as a single-user app with full operational access so judges can immediately test all features.



**Core Features & Workflows:**

1. **Cat Intake & Profiles:** Quick intake form with photo upload, microchip ID, color/breed tags, health condition notes, and intake location tracking.

2. **Health & Medical Tracking:** Log spay/neuter status, vaccination records, daily medication schedules, dietary needs, and vet appointment logs.

3. **Shelter Workflow Board:** Interactive board to move cats across operational stages (Intake, Medical Hold, Available for Adoption, Adopted, Foster Care).

4. **Daily Operations Checklist:** Interactive checklist for staff and volunteers to manage daily feedings, medication administration, and habitat cleaning routines.

5. **Adoption & Application Queue:** Manage incoming adoption applications, review applicant details, and display live shelter capacity metrics.



**AI Feature:**

- **AI Adoption Bio Generator:** Include an AI button on each cat profile that generates an engaging, adoption-ready bio and social media caption from intake traits and health notes, complete with an inline editing field.



**Integrations:**

- **Email Notifications (Resend):** Automatically send an email notification with applicant details to shelter staff whenever a new adoption application is submitted.



**Design & Theme:**

- **Theme:** Warm, friendly, cat-inspired palette. Primary accent: Soft terracotta (#E07A5F), Background: Warm cream (#FDF0ED), Text: Deep slate (#2B2D42).

- **UI Layout:** Mobile-optimized with bottom tab navigation (Dashboard, Cats, Tasks, Applications), rounded cards (rounded-xl), and color-coded status badges (Emerald for Available, Amber for Medical Hold, Rose for Priority Intake).
